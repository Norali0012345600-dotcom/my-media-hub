# MY MEDIA HUB — النسخة الأولى

منصة ويب عربية داكنة (PWA) تجمع روابط مصادر ترفيه مجانية وقانونية في واجهة واحدة.

## الملفات
- `index.html`: هيكل الواجهة.
- `styles.css`: التصميم المتجاوب.
- `app.js`: البحث والتصفية والمفضلة المحلية.
- `manifest.webmanifest`: إعدادات التثبيت كتطبيق ويب.
- `sw.js`: تخزين ملفات الواجهة مؤقتاً للعمل دون اتصال.
- `icon.svg`: أيقونة المنصة.

## التشغيل
يمكن فتح `index.html` مباشرة لمعاينة الواجهة والوظائف الأساسية. بعض مزايا PWA مثل Service Worker والتثبيت تتطلب نشر الموقع عبر HTTPS أو تشغيله على localhost.

## النشر المجاني
1. أنشئ مستودعاً عاماً أو خاصاً في GitHub.
2. ارفع جميع الملفات مع الحفاظ على أسماء المجلدات.
3. من Settings ثم Pages اختر Deploy from a branch، وحدد `main` والمجلد `/root`.
4. افتح رابط GitHub Pages عبر Safari على iPhone.
5. في Safari اضغط مشاركة ثم Add to Home Screen.

بدائل الاستضافة: Cloudflare Pages أو Netlify (خطط مجانية بشروطها). لا تحتاج قاعدة بيانات أو حساباً للنسخة الأولى.

## ملاحظات
- المفضلة محفوظة محلياً في متصفح الجهاز، ولا تتم مزامنتها بين الأجهزة.
- الروابط الخارجية تفتح في خدماتها الرسمية؛ لا يتم تجاوز الاشتراكات أو DRM.
- مجانية المصدر لا تعني أن كل عنوان مجاني في كل بلد. تحقق من حقوق كل عنوان وتوفر الخدمة في السعودية.
- التخزين دون اتصال يخص ملفات واجهة المنصة فقط، وليس تنزيل الأفلام أو الموسيقى من الخدمات الخارجية.
- لا تضع بيانات شخصية أو كلمات مرور في هذه النسخة التجريبية.

## تطويرات النسخة التالية
حسابات اختيارية ومزامنة سحابية، RSS للبودكاست، تكامل Jellyfin للمكتبة الشخصية، مشغل للملفات التي تملكها، واختبارات وصولية وأداء.
