# MY MEDIA HUB 2.0

نسخة مطورة من مركز الترفيه الشخصي، بواجهة عربية داكنة ومتجاوبة.

## محتويات النسخة
- بطاقات اكتشاف وتصنيف للمصادر.
- بحث وتصفية حسب النوع.
- نافذة تفاصيل وروابط مباشرة للمصادر.
- قائمة مفضلة محفوظة محلياً.
- مشغل محلي لملفات الصوت والفيديو التي يختارها المستخدم من جهازه.
- PWA وService Worker لتخزين ملفات الواجهة.

## التحديث على GitHub
1. افتح مستودع `my-media-hub`.
2. اختر Add file ثم Upload files.
3. ارفع ملفات الحزمة الجديدة إلى جذر المستودع، مع استبدال الملفات ذات الأسماء نفسها.
4. اضغط Commit changes.
5. انتظر اكتمال GitHub Pages ثم حدّث الموقع في Safari.

## تنبيه مهم
المشغل يشغّل ملفات يختارها المستخدم محلياً فقط؛ لا يقوم بتنزيل أو تجاوز حماية خدمات البث. روابط المحتوى تفتح في المواقع الرسمية. توفر العناوين المجانية يختلف حسب البلد والترخيص.
المفضلة محلية على المتصفح ولا تتزامن بين الأجهزة.
ربط Jellyfin لم يُفعّل بعد: يتطلب عنوان خادم Jellyfin يعمل وإعداد وصول آمن، ولا تضع كلمات المرور في ملفات عامة أو ترسلها في المحادثة.


## إضافة مكتبة الأفلام والمسلسلات
- تصنيفات متعددة: أكشن، مغامرات، أنيميشن، كوميديا، جريمة، وثائقي، دراما، عائلي، فانتازيا، تاريخي، رعب، غموض، رومانسي، خيال علمي، رياضي، إثارة وتشويق، حرب، ويسترن، استعراضي/موسيقي، واقعي، وسيرة ذاتية.
- أضيفي فيلماً أو مسلسلاً من زر «إضافة عنوان».
- للمسلسلات حددي عدد المواسم/الأجزاء وعدد الحلقات الافتراضي لكل موسم.
- يمكن اختيار الموسم والحلقة من بطاقة المسلسل.
- تحفظ المكتبة على نفس المتصفح محلياً.
- أضيفي رابطاً قانونياً اختيارياً لفتح المصدر الرسمي.
